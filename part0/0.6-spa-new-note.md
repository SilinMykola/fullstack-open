# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User writes a note and clicks Save

    Note right of browser: The form submit handler in spa.js prevents the default page reload
    Note right of browser: The new note is added to the notes list and the list is rendered again

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of browser: Request body is JSON: { "content": "my new note", "date": "..." }
    Note left of server: Server adds the new note to the notes array
    server-->>browser: 201 Created { "message": "note created" }
    deactivate server

    Note right of browser: The page is not reloaded, no other requests are made
```
